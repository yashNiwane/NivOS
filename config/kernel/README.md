# NivOS Kernel Packages

This directory caches pre-built custom Linux kernel `.deb` packages (image, headers, libc-dev) generated by `scripts/01_fetch_and_build_kernel.sh` or `scripts/rebuild_kernel_for_vms.sh`.

Compiled binary deb packages are excluded from Git to maintain a clean source repository.
When running `./build.sh --kernel` or `./build.sh --all`, the kernel will be automatically compiled from upstream sources with NivOS low-latency configuration (`CONFIG_PREEMPT_DYNAMIC`, `CONFIG_ZRAM`, `CONFIG_SQUASHFS_ZSTD`, and hypervisor DRM drivers).
